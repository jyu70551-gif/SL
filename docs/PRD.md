# SL 제작 주문서 (PRD)

> PRD는 "무엇을 만들어 달라"고 적는 주문서입니다.
> [mvp.md](mvp.md)에서 정한 범위만 담았고, 새 기능은 넣지 않았습니다.
> 아직 정하지 않은 내용은 **미정**으로 표시했습니다.

## 1. 누가 사용하는 서비스인가요?

| 항목 | 내용 |
|---|---|
| 서비스 이름 | SL |
| 사용자 | 편의점 점주 (첫 버전은 **본인 한 명**) |
| 점포 | **한 곳** (시흥시 거모동, 주택가이면서 시장·장날이 있는 골목 근처) |
| 주로 보는 시간 | 근무를 마친 뒤 (저녁·야간 마감 무렵) |
| 주로 쓰는 기기 | **스마트폰** (PC 화면도 무난하게 보이도록 합니다) |
| 접속 방법 | **인터넷에 올려서** 스마트폰으로 어디서나 접속 (첫 버전은 웹 사이트이고, 나중에 앱으로 확장할 수 있도록 구조를 열어 둡니다) |
| 만드는 기술 | 화면은 **React**, 서버는 **FastAPI**, 데이터 보관은 **Supabase** (개발·시험 중에는 **SQLite**) |
| 로그인 | 없음 (회원가입·여러 계정 없음) |
| 접근 제한 | **간단한 비밀번호 하나**를 입력해야 화면이 열림 |

## 2. 어떤 불편을 해결하려는가요?

1. **하루 매출을 정리하는 일이 번거롭습니다.**
   상가 프로그램에서 뽑은 매출 자료가 표 형태로 길게 나와서, 하루가 어땠는지 한눈에 보기 어렵습니다.

2. **평소와 다르게 팔린 항목을 놓치기 쉽습니다.**
   어떤 대분류가 이상하게 많이 또는 적게 팔려도, 숫자를 하나씩 비교하지 않으면 알아채기 어렵습니다.

3. **즉석식품(삼각김밥, 햄버거 등) 발주가 어렵습니다.**
   오래 보관할 수 없어서, 너무 많이 시키면 버리게 되고 너무 적게 시키면 못 팝니다. 얼마나 시켜야 할지 감을 잡기 어렵습니다.

4. **내일 장사가 어떨지 가늠하기 어렵습니다.**
   요일, 장날, 날씨, 방학, 명절에 따라 매출이 달라지는데 이를 머릿속으로만 따져야 합니다.

## 3. 사용자가 각 기능으로 무엇을 할 수 있나요?

### 기능 1. 매출 파일 올리기

- 상가 프로그램에서 뽑은 **CSV 파일**을 올립니다.
- 파일의 열은 PDF와 같습니다: **상품코드, 대분류, 판매수량, 판매액, 연도, 달, 일, 요일**
- 올릴 때 **"몇 시까지의 매출인지"** 시각을 **직접 입력**합니다.
- 올린 데이터는 **계속 쌓입니다.**
- 같은 날짜의 파일을 다시 올리면 **새 파일로 덮어씁니다.** 덮어쓰기 전에 **확인 창**을 띄웁니다.
- 나중에 포스기(계산대)와 자동으로 연결할 수 있도록 구조는 열어 둡니다. 첫 버전에서는 파일 올리기만 합니다.

### 기능 2. 확인이 필요한 대분류 보기 (핵심 기능)

- 대분류별 매출을 **날짜 순서의 그래프**로 볼 수 있습니다.
- 평소와 크게 다른 날이 있는 대분류가 **"확인이 필요한 대분류"** 목록에 올라옵니다.
  - 같은 요일끼리 비교해서 크게 벗어나면 후보가 됩니다. 이 판단은 **통계**가 합니다.
  - 통계적 근거가 있는 방법을 쓰고, **거의 늘 0인 대분류는 따로 처리**합니다. (구체적인 계산법은 설계 단계에서 확정합니다)
- 항목마다 **AI가 이유를 설명**합니다. AI는 **OpenAI(ChatGPT 계열)** 를 씁니다.
  - 숫자 근거를 먼저 말합니다.
  - 원인은 "~일 수 있습니다"처럼 **가능성**으로만 말합니다. 단정하지 않습니다.
  - 예: "담배가 같은 요일 평소의 3배입니다. 대량 구매 또는 입력 오류일 수 있습니다."
- 항목을 누르면 **그 대분류의 그래프가 열리고, 이상한 날이 표시됩니다.**
- 항목마다 **"확인함·정상"** 이라고 답할 수 있습니다. 답한 항목은 **목록에서 사라지고** 다시 경고로 뜨지 않습니다. 실수로 눌렀을 때는 **"확인한 항목" 보기에서 취소**할 수 있습니다.

### 기능 3. 오늘 총매출·판매수량 보기

- 오늘의 **총매출**과 **총 판매수량**을 봅니다.
- **같은 요일과 비교**한 결과를 봅니다.

### 기능 4. 즉석식품 요약 보기

- **간편식사**와 **즉석조리** 두 대분류의 오늘 판매량을 봅니다.
- **평소 범위와 비교**해서 많은지 적은지 봅니다.
- 상품 하나하나가 아니라 **대분류 단위**입니다. (상품별 자료가 없기 때문입니다.)

### 기능 5. 내일 예상 매출 보기

- 내일 매출이 **어느 정도일지 예상 범위와 가운데 값**을 봅니다. (예: "약 12만 원, 범위 10~14만 원")
- 매출에 영향을 주는 요인을 넣은 **회귀모형**으로 예상 범위를 계산합니다. (구체적인 모형은 설계 단계에서 확정합니다)
- 고려하는 요소는 **요일, 장날, 날씨, 방학 여부, 명절·공휴일**입니다.
  - 날씨는 **기상청 공공 데이터**(시흥시 기준)를 씁니다.
  - 공휴일·명절은 **공공 데이터**에서 가져옵니다.
  - 방학은 **점주가 시작·끝 날짜를 직접 입력**합니다. (입력하는 곳은 화면 E 설정)
  - 장날은 5일장으로 **3, 8, 13, 18, 23, 28일**입니다.
- 데이터가 적어서 **"참고용"** 이라고 화면에 표시합니다.

### 모든 기능에 공통

- 모든 카드에 **"몇 시까지의 매출인지"** 를 표시합니다. (근무가 끝날 때쯤 자료를 뽑아서, 하루 전체가 아닐 수 있기 때문입니다.)

## 4. 어떤 화면이 필요한가요?

### 화면 A. 초기 화면 (카드형, 폰 기준)

위에서 아래로 카드가 쌓인 모양입니다. 순서는 다음과 같습니다.

| 순서 | 카드 | 보여주는 내용 |
|---|---|---|
| 1 | 확인이 필요한 대분류 | 평소와 크게 다른 항목과 AI 설명 |
| 2 | 오늘 총매출·판매수량 | 오늘 합계, 같은 요일과의 비교 |
| 3 | 즉석식품 요약 | 간편식사·즉석조리의 오늘 판매량과 평소 범위 비교 |
| 4 | 내일 예상 매출 | 예상 범위와 가운데 값 ("참고용" 표시) |

**데이터가 아직 적은 동안:** 같은 요일 비교, 이상치, 예상 매출 카드는 자리를 유지한 채 **"데이터가 더 필요해요"** 안내와 진행 상황을 보여줍니다. (예: "같은 요일 비교는 ○일 더 쌓이면 보여요") 몇 일 치부터 보여줄지는 **미정**입니다. (아래 미정 7번과 함께 정합니다)

### 화면 B. 대분류 그래프 화면

- 초기 화면의 "확인이 필요한 대분류" 항목을 누르면 **새 화면**으로 열립니다.
- 그 대분류의 **날짜별 매출 그래프**와 **이상한 날 표시**를 보여줍니다.
- 여기서 **"확인함·정상"** 이라고 답할 수 있습니다. 답한 항목은 홈의 목록에서 사라집니다.
- 확인한 항목을 모아 보고 **취소**할 수 있는 "확인한 항목" 보기가 있습니다. 홈의 "확인이 필요한 대분류" 카드 안 **링크**로 들어갑니다. (하단 메뉴는 늘리지 않습니다)

### 화면 C. 파일 올리기

- CSV 파일을 고르고, **몇 시까지의 매출인지** 시각을 입력해 올리는 화면입니다.
- 같은 날짜 파일을 다시 올리면 덮어쓰기 **확인 창**이 뜹니다.

### 화면 D. 비밀번호 입력

- 서비스에 들어올 때 **비밀번호 하나**를 입력하는 화면입니다.
- 다른 사람이 주소만 알아서 내 매출을 보는 일을 막습니다.

### 화면 E. 설정 (방학 날짜, 비밀번호 바꾸기)

- 점주가 **방학 시작·끝 날짜**를 입력하는 화면입니다. **여러 기간**을 입력할 수 있고, 목록에서 각 기간을 **수정·삭제**할 수 있습니다.
- 점주가 정해 둔 **비밀번호를 바꿀 수** 있습니다.

### 화면 이동 방법

폰 **하단 메뉴**로 세 곳을 오갑니다.

| 메뉴 | 열리는 화면 |
|---|---|
| 홈 | 화면 A (초기 화면, 카드). 화면 B는 여기서 항목을 눌러 들어갑니다. |
| 파일 올리기 | 화면 C |
| 설정 | 화면 E |

화면 D(비밀번호)는 서비스에 처음 들어올 때 한 번 나옵니다.

## 5. 어디까지 되면 첫 버전이 완성된 것인가요?

아래를 **모두** 만족하면 완성입니다.

- [ ] 마감 후 CSV 파일을 올리면 **1분 안에** 카드들이 채워진 화면이 보입니다.
- [ ] 올린 데이터가 **쌓이고**, 다음 날 올려도 이어서 반영됩니다.
- [ ] 평소와 다른 날이 있으면 **"확인이 필요한 대분류"** 에 올라오고, 이유가 **쉬운 말로** 설명됩니다.
- [ ] AI 설명이 **숫자 근거를 먼저** 말하고, 원인은 **가능성으로만** 말합니다.
- [ ] 항목을 누르면 대분류 **그래프와 이상한 날 표시**가 보입니다.
- [ ] 이상치 항목에 **"확인함·정상"** 이라고 답할 수 있고, 답한 항목은 다시 경고로 뜨지 않습니다.
- [ ] 오늘 총매출·판매수량과 같은 요일 비교가 보입니다.
- [ ] 간편식사·즉석조리의 평소 범위 비교가 보입니다.
- [ ] 내일 예상 매출이 **범위와 가운데 값으로, "참고용" 표시와 함께** 보입니다.
- [ ] 모든 카드에 **몇 시까지의 매출인지** 표시됩니다.
- [ ] 점주가 **방학 시작·끝 날짜**를 입력할 수 있습니다.
- [ ] 점주가 설정에서 **비밀번호를 바꿀 수** 있습니다.
- [ ] 하단 메뉴로 **홈 / 파일 올리기 / 설정**을 오갈 수 있습니다.
- [ ] **스마트폰 화면에서** 보기 편합니다.
- [ ] 인터넷 주소로 접속할 수 있고, **비밀번호를 입력해야** 화면이 열립니다.
