# SL 디자인 가이드

> 점주가 정한 참고 화면(짙은 남색 배경의 카드형 대시보드)의 **분위기만** 가져와, SL의 내용으로 새로 만드는 규칙입니다.
> 참고 화면의 제품 이름·로고·문구는 쓰지 않습니다. PRD에 없는 기능(작업 목록, 상단 탭, 담당자 전송, 기여 요인 막대 등)은 넣지 않습니다.

## 정해진 것

- **어두운 테마로 고정**합니다. (폰의 밝은/어두운 모드 설정을 따라가지 않습니다)
- **폰 화면 기준**의 한 줄 카드입니다. 위에서 아래로 쌓고, 좌우 여백은 16px입니다.
- **Phase 3에서 홈 카드를 만들 때 함께 적용**하고, 이미 만든 로그인·하단 메뉴·파일 올리기 화면도 같은 틀로 맞춥니다.

## 글꼴

- **Pretendard**(무료 오픈 글꼴, SIL OFL 라이선스)를 씁니다. 프로젝트에 포함해서 쓰므로 인터넷 연결과 상관없이 같은 모양으로 보이고, 글자가 필요할 때 필요한 조각만 불러옵니다.
- 불러오지 못하면 기기 기본 글꼴(맑은 고딕 등)로 대신 보입니다.
- 큰 숫자는 폭이 같은 숫자꼴(`tabular-nums`)로 맞춰서, 금액이 바뀌어도 자릿수가 흔들리지 않게 합니다.
- 한글은 단어 중간에서 줄바꿈하지 않습니다(`word-break: keep-all`).

## 색 (제안값, 만들면서 눈으로 보고 조정)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 배경 | `#0b0e17` | 화면 바탕 |
| 카드 | `#121626` | 카드, 하단 메뉴 |
| 테두리 | `#232a40` | 카드 가장자리 (1px) |
| 글자 | `#e8ebf5` | 제목, 큰 숫자 |
| 보조 글자 | `#98a2b8` | 설명, 단위 |
| 강조 | `#7c8cff` | 현재 메뉴, 주요 버튼, 실제 값 그래프선 |
| 하락·주의 | `#ff8a8a` | 감소, 이상 표시 |
| 상승·정상 | `#5be0a0` | 증가 |
| 경고 칩 | `#f0b35a` | "주의", "참고용" |

## 색의 쓰임과 글자 크기

색은 다크 네이비·연보라·앰버를 유지합니다.

- **앰버(`#F6B94A`):** 주요 버튼, 활성 메뉴, **확인 필요 표시**(⚠ 아이콘, 확인할 사항 제목 앞의 점, 식품군의 "평소보다 많음/적음")에만 씁니다. 항상 아이콘과 문구를 함께 씁니다. 버튼 글자는 어두운 색(`#1a1204`).
- **연보라(`#7C8CFF`):** 그래프의 실선과 선택 상태(선택한 날짜의 점, 링크 글자)에 씁니다.
- **홈 총매출 카드의 증감만 방향 색을 씁니다.** 증가는 민트(`#47D7AC`)와 ▲, 감소는 코랄(`#FF8A75`)과 ▼, 같으면 회색과 —입니다. 총매출 숫자는 흰색을 유지하고, 증가·감소 문구를 함께 써서 색만으로 전달하지 않습니다. 비교 자료가 없으면 "비교 자료가 부족해요", 비교 기준이 0원이면 증가율 없이 금액 차이만 보여줍니다. 이 색은 **매출 변화 방향**만 뜻하며 정상(✓, 중립 회색)·주의(⚠, 앰버) 판정 색과 구분합니다.
- **그 밖의 화면에서는 증가·감소를 색으로 칭찬·경고하지 않습니다.** 판매가 늘었다고 항상 좋은 것은 아니므로, 금액 차이는 같은 흰색 글자에 ▲/▼ 기호와 "많아요/적어요" 문구로만 구분합니다. (증가율을 초록으로 강조하지 않습니다)
- **핵심 숫자는 흰색**, 설명 글자는 충분히 밝은 회색(`#B9C2D6`)입니다.
- **글자 크기:** 본문 16px, 보조 설명 14px 이상, 핵심 매출 34px, 섹션 제목 18px. 누를 수 있는 줄과 버튼은 높이 44px 이상(버튼은 48px)입니다.

## 홈의 구성 (점주가 빠르게 읽기 위한 재구성)

색은 기존 네이비·연보라를 유지하고, 홈을 **세 영역**으로 나눕니다. 위에서 아래 순서입니다.

1. **매출 요약** — 오늘 총매출, 오늘 판매수량
2. **확인할 사항** — 평소와 판매 변화가 큰 대분류 (이전 이름: 확인이 필요한 대분류)
3. **집중 관리 식품군** — 간편식사·즉석조리 (이전 이름: 즉석식품 요약)

**규칙**
- **날짜와 집계 시각은 화면 맨 위에 한 번만** 보여줍니다. (예: 2026년 2월 25일 (수) · 오전 8시까지 집계) 영역마다 시각 칩이나 바닥 글을 반복하지 않습니다.
- **카드 안에 카드를 만들지 않습니다.** 항목은 여백과 **얇은 구분선**으로 나눕니다.
- **배지·버튼을 항목마다 반복하지 않습니다.** 확인할 사항은 **한 줄 전체가 링크**이고, 기록하는 버튼은 상세 화면에만 둡니다. 경고·정상은 배지 대신 ⚠/✓ 아이콘과 문구로 표시합니다.
- **숫자의 순서:** ① 핵심 금액(가장 크게, 흰색) → ② 금액 차이 문장(▲/▼, "같은 수요일 기준보다 30,000원 많아요") → ③ 증가율(작고 약하게) → ④ 판매 수량. 같은 금액·증가율·설명을 한 화면에서 두 번 보여주지 않습니다.
- **준비 중인 기능은 홈에서 숨깁니다.** (내일 예상 매출은 만들어질 때 홈에 나타납니다)
- **확인할 사항:** 분석 날짜가 가장 최근 올린 날이면 "오늘의 변화", 그 전 날짜는 "이전 미확인 사항"으로 나눕니다. 한 줄은 `분류명 · 발생 날짜` → 판매액 → 비교 금액 차이 → 증가율 순서이고, 날짜는 작은 각주로 숨기지 않습니다.
- **집중 관리 식품군:** 진행률 같은 막대 없이 `분류 · 판매 수량 · 비교 범위 · 상태` 표로 보여줍니다. 비교할 자료가 모자라면 "판단 자료 부족"이라고 표시합니다.
- **상세 화면의 순서:** 핵심 결과(제목, 분석 날짜·집계 시각, 판매액, 비교 문장) → 그래프 → 운영 상황 기록. 상단과 같은 숫자를 다시 보여주는 카드는 없습니다.
- **그래프:** 가로축은 실제 날짜 간격이고, 파일을 올리지 않은 날(미수집)은 0원으로 채우지 않고 선을 잇지도 않습니다. 실제 0원인 날은 0원 점으로 그대로 보입니다. 세로축 눈금은 데이터 범위에 맞고 값과 글자가 정확히 같습니다. 곡선 보간 없이 직선으로 잇고, 그림자·발광·그라데이션·면적 채우기는 쓰지 않습니다.
  - 두께·반지름은 **실제 화면 CSS px** 기준입니다. 그래프를 화면 폭 그대로(1단위 = 1px) 그리는 직접 만든 SVG이고 차트 라이브러리를 쓰지 않으므로 기본 스타일이 덮어쓰지 않습니다. 값은 `SalesChart.jsx`의 `CHART_STYLE` 한 곳에서 정하고 범례도 같은 값을 씁니다.
  - 실제 판매액 선 `#939BFF` 1.5px / 비교 기준선 `#B1B8CA` 1px, 점선 4 4 / 가로 그리드 `#394158` 1px 실선 / 세로 그리드 `#2B3248` 1px(주요 날짜 4~5개만) / 일반 점 반지름 2px / 선택한 점 반지름 5px·테두리 2px(흰 바탕, 연보라 테두리) / 선택 날짜 안내선 1px 약한 점선.
  - 그리드는 데이터 선 뒤에 그리고, 가로 그리드가 세로 그리드보다 분명합니다. 선택한 점의 금액 라벨은 점·판매선·기준선·안내선·차트 경계와 겹치지 않는 자리로 옮깁니다.

**바뀐 말** (화면 문구만 바뀌고 동작은 같습니다)

| 이전 | 지금 |
|---|---|
| 이상한 날 | **판매 변화가 큰 날** |
| 확인함·정상 | **운영 상황 기록** (취소는 "기록 취소") |
| 확인한 항목 | **운영 상황 기록** 화면 |

## 카드의 모양 (이전 규칙 — 위 "홈의 구성"이 우선합니다)

1. 맨 위: 작은 이름(예: 오늘 총매출)과 오른쪽 칩(예: **주의**, **참고용**)
2. 큰 숫자 한두 개와 변화율(▲ 초록 / ▼ 빨강)
3. 그래프나 막대
4. 한두 줄 설명 (AI 설명은 "AI" 배지가 붙은 작은 상자)
5. 맨 아래: 시각 표시(예: 오후 10시까지) — **모든 카드에 반드시** 넣습니다. (PRD)
6. 버튼은 카드당 최대 두 개

모서리는 둥글게(12~16px), 카드 사이 간격은 16px로 합니다.

## 그래프 규칙

- **실제 값**은 실선(강조색), **평소 값**(같은 요일 평균)은 점선입니다.
- **예상 범위**는 옅은 띠로 보여주고 가운데 값은 선으로 표시합니다.
- **이상한 날**에는 점과 작은 말풍선을 붙입니다.
- 막대 비교(즉석식품)는 오늘 값과 평소 범위를 한 줄에 함께 보여줍니다.

## 카드별 적용

| 카드 | 구성 |
|---|---|
| 확인이 필요한 대분류 | 대분류 이름, "주의" 칩, 변화율, 평소와 비교한 그래프, AI 설명 상자, [그래프 보기] [확인함·정상] |
| 오늘 총매출·판매수량 | 큰 숫자 두 개, 같은 요일 평균과의 비교(▲/▼ %), 시각 |
| 즉석식품 요약 | 간편식사·즉석조리 각각 오늘 판매수량과 평소 범위 막대, 시각 |
| 내일 예상 매출 | 가운데 값, 예상 범위 띠, **"참고용"** 칩, 빠진 정보가 있으면 안내 |
| 데이터가 적을 때 | 카드 자리는 유지하고 "데이터가 더 필요해요"와 진행 상황 (오류처럼 보이지 않게 보조 글자색 사용) |

## 읽기 쉬움 규칙

- **색만으로 구분하지 않습니다.** 증가/감소에는 ▲ ▼ 기호와 +/− 부호를 함께 씁니다.
- 글자와 배경의 대비를 충분히 둡니다. 설명 글자도 읽을 수 있는 밝기를 유지합니다.
- 버튼과 메뉴는 손가락으로 누르기 쉽게 높이 48px 이상으로 합니다.
- 숫자는 천 단위 쉼표를 붙이고, 금액은 원 단위로 보여줍니다.

## 쓰지 않는 것 (PRD 범위 밖)

- 왼쪽 작업 목록, 상단 기능 탭, LIVE 표시
- "점검 업무 생성", 담당자·소담 전송 같은 업무 연결 버튼
- 하락 기여 요인 막대(−32% 등) — 요인 분석은 데이터가 쌓인 뒤에 따로 정합니다.
- "추천 정확도 90%" 같은 정확도 문구 — 데이터가 적은 동안은 "참고용"으로만 표시합니다.

## 총매출 분석 화면

> 아래는 이전 구성입니다. 현재 구성은 [spec.md](spec.md)의 "총매출 분석 화면의 구성 (점주용 재구성)"과 이 문서 맨 아래의 "차분한 분석 화면"을 따릅니다.

- 순서: 핵심 결과(오늘 총매출, 평소 중심값과의 차이 문장, 통계 결과 한 문장) → 시계열 그래프 → "오늘은 평소 분포의 어디쯤일까요?" 표.
- 통계 결과 문장은 **⚠ 앰버**(유의미한 증가·감소), **✓ 중립색**(유의미하지 않음), **회색**(판단 자료 부족)입니다. 매출 방향 색(민트·코랄)은 금액 차이 문장에만 씁니다.
- 그래프의 평소 중심값은 점선(4 4), 95% 예상 범위는 가는 점선(1 4)입니다. 범례도 같은 모양입니다. (요일 구분이 없어서 같은 요일 표시는 쓰지 않습니다)

## 차분한 분석 화면 (매출 점검 · 분석 상세)

장식보다 정보의 우선순위에 집중합니다. 핵심 숫자 → 해석 → 다음 행동 순서로 읽힙니다.

- **색(전체 화면 공통):** 배경 `#0C1019`, 카드 `#151C2C`, 구분선·테두리 `#2A3346`, 핵심 글자 `#F3F5FA`, 설명 글자 `#B7C0D0`, 그래프·선택 상태 `#969FFF`, 매출 증가 `#47D7AC`, 매출 감소 `#FF8A75`, 주요 행동·확인 필요 `#F6B94A`. 포인트 색은 카드 배경이나 긴 본문에 쓰지 않습니다.
- **그림자·발광·유리 효과·장식용 그라데이션을 쓰지 않습니다.** (배경과 카드의 그라데이션도 없앴습니다)
- **글자(분석 화면):** 제목 22px/600, 총매출 36px/700, 섹션 제목 18px/600, 본문 16px/400(줄 높이 1.6), 보조 14px/400. 금액은 `tabular-nums`. 금액·제목 외에는 굵게 쓰지 않습니다.
- **여백(분석 화면):** 좌우 20px, 섹션 간격 28px, 카드 안 20px, 모서리 16px, 테두리 1px. 상단 요약은 카드 테두리 없이 배경 위에 둡니다. 카드 안에 카드를 만들지 않습니다.
- **버튼·링크:** 주요 버튼은 앰버 배경에 진한 글자, 높이 48px 이상. 보조 행동은 텍스트 버튼. 링크는 밑줄 대신 "문구 + 작은 화살표"입니다. 아이콘은 한 종류의 선형(두께 1.75) 아이콘으로 통일합니다. (`components/Icons.jsx`)
- **상호작용:** 전환 효과 160~180ms, 키보드 포커스는 2px 연보라 윤곽선으로 분명히 보입니다.
- **증감 색의 뜻:** 민트·코랄은 매출 **변화 방향**일 뿐 경고나 정상 판정이 아닙니다. 확인이 필요한 항목에만 앰버 ⚠를 씁니다.
